# ATEAM v2 — 설계 요약

> 2026-10-13 · 기준: **도구의 주인은 팀장. 팀원에게는 '여기 올리면 나도 편하다'는 이유를 준다.**

## 1. 원칙
- 팀원 입력 상한: 주 1회 체크인(2~3분) + 필요할 때 공유 + 팀장 요청에 답하기. 나머지는 전부 여기서 파생
- 팀 유형 분류는 하지 않는다. 팀 특성은 팀장이 '내 노하우'에 말로 넣고, 업무 성격은 과제 단위(프로젝트 / 정기 업무)로 정한다
- 일은 각자의 전문 툴에서, 흔적·판단·피드백은 ATEAM에서 (파일·링크·캡처·숫자·글 무엇이든)
- AI는 언제나 '제안'하고 사람이 수락한다. 숫자는 계산 모델 값만 쓴다

## 2. 목표·과제 (자유 구조)
- 모든 항목은 같은 카드(`work_items`), 단계 수·단계 이름 자유 (기본 목표 › 과제 › 할 일, 설정에서 OKR 등으로 변경)
- 필수 입력은 제목 하나. 진척 방식은 항목마다: 완료 체크 / 하위 항목 기준 / 퍼센트 / 숫자 목표(실적 지표 연결 가능) / 정기 업무
- 편집: 아웃라인(Enter·Tab·Shift+Tab·드래그) · 표(엑셀처럼, 붙여 넣어 한꺼번에 추가) · 타임라인(막대 끌기)
- AI: 계획서·업무 분장 → 전체 초안 / "제안서 마감 2주 미루고 김도현에게" → 변경안 (추가·수정·이동·중단을 항목별로 수락)
- **팀원이 스스로 만든다**: 팀장이 목표를 맡기고 '계획 세우기' 요청 → 팀원이 하위 과제를 쓰거나 AI로 초안 → '검토 대기' → 팀장 승인 / 수정 요청(코멘트) → 팀원이 고치면 자동 재제출
- 기준선: 승인 순간의 일정이 처음 계획으로 저장. 이후 일정·목표값 변경은 사유와 함께 이력, 팀장 알림
- 계획 대비: 처음 마감 대비 지연일, 변경 횟수, 최근 3주 진척 속도로 예상 완료일·지연 예측
- 팀장 피드백 코멘트는 평가 근거로 쌓인다. 팀원 권한(자유 편집)은 팀장이 설정에서 켠다

## 3. 팀원 화면 (팀장 화면과 분리)
- 홈: 팀장 요청 · 내 목표·과제 빠른 진척 입력 · 최근 받은 피드백 · 체크인/공유/1:1 바로가기 · 팀장 가이드
- 내 목표·과제: 맡은 목표 아래 계획 세우기(직접·붙여 넣기·AI 초안), 승인 상태 확인, 말로 고치기(내 항목만)
- 체크인: 진척 체크가 체크인 안에 들어 있음 → 진척 이력이 자동으로 쌓임
- 공유하기: 파일·캡처 / 링크 / 숫자 업데이트 / 글, 승인·피드백·공유만 선택, 올리기 전 AI 셀프 점검(팀장이 공개한 기준)

## 4. 팀장 홈 = 관제판
- 관리 영역 5개(목표·실적, 실행·과제, 사람·컨디션, 결과물·리뷰, 육성·평가) 상태·핵심 숫자·데이터 충실도
- AI가 찾은 것: **오늘 / 이번 주 / 이번 달** 탭. 기간마다 AI 인사이트(엮어서 해석·우선순위·할 일) + 자동 감지 신호(규칙·모델, 근거 표시)
- 신호 엔진 하나를 홈과 AI가 같이 씀: `supabase/functions/_shared/signals.ts`
- 오늘 할 일(작게): 1:1 · 리뷰 대기 · 내 약속 · 팀원 계획 검토
- 알림 종: 요청·검토 요청·피드백·결과물·막힘·일정 변경

## 7. 데모 계정
- `supabase/demo_accounts.sql`(대시보드 `06_demo_accounts.sql`)을 SQL Editor에서 Run → 고정 데모 계정 7개(팀장 `leader@demo.ateam`, 팀원 jung·park·lee·kim·han·choi `@demo.ateam`, 공통 비밀번호)와 6개월치 '전략기획팀 (데모)' 기록 생성. 다시 Run하면 초기화
- 팀원별 체험 시나리오: 정우성(계획 세우기 요청 → AI 초안) · 박서연(공유 요청 → 캡처·링크) · 이정규(이번 주 체크인 미제출) · 김도현(리뷰 중 기획서 새 버전, 오늘 1:1) · 한수진(진척 요청) · 최민아
- 팀장·팀원 동시 확인은 시크릿 창. 데이터 본문은 `seed_demo_team()` 하나로, 로컬 `seed.sql`도 같은 함수를 씀
- `teams.is_demo`: 팀 수 한도 제외, 예약 AI 인사이트는 만든 뒤 14일만
