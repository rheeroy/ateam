# ATEAM — 팀장 가치제안(VP) 관점 검토 v1.0

> 2026-10-11 · 이름 확정: **ATEAM** · 대상: 팀장 개인 구독

## 1. 한 줄 가치제안
**"내 방식대로 일하는 AI 팀장 비서 — 주간보고·리뷰·1:1·평가에 쓰던 시간을 줄이고, 팀원을 놓치지 않게."**

## 2. '내 노하우' 설계 결정
| 방식 | 장점 | 문제 |
|---|---|---|
| 그냥 때려 붓기(원문 그대로 저장) | 넣기 편함 | 매번 원문 전체를 프롬프트에 → 비용↑, 어느 기준이 쓰였는지 안 보임, 오래된 자료가 섞임 |
| 양식 입력(항목별 폼) | 정확 | 팀장이 안 씀. 진입장벽 |
| **채택: 붓기 → AI가 카드로 정리 → 팀장 확인** | 넣기는 편하고, 쓰이는 건 짧고 명확 | 정리 1건 2 크레딧 |

- 카드 종류: 원칙 · 평가 기준 · 프레임워크 · 사업 맥락 · 코칭 방식 · 용어
- 카드마다 '반영할 곳'(리뷰·주간보고·1:1·브리핑·평가·전략·시나리오) 지정 → 해당 기능 프롬프트에 기능별 최대 약 2,600자만 주입, 고정핀 우선
- AI가 카드를 근거로 쓰면 사용 횟수 집계 → 팀장이 "내 기준이 실제로 쓰이고 있다"를 봄
- 팀장이 고친 카드는 ✎ 팀장 수정으로 표시. '팀원에게 공개'한 카드는 팀원 체크인·결과물 화면에 '팀장 가이드'로 노출 → 팀원이 올리기 전에 기준을 앎
- 넣는 방법: 붙여넣기 / 파일(PDF·Word·PowerPoint·텍스트) / 직접 카드 추가(무료)

## 3. VP 체크리스트와 반영 사항
| 팀장이 묻는 것 | 이전 | 반영 |
|---|---|---|
| 첫날 혼자 써도 가치가 있나? | 팀원 데이터가 없으면 빈 화면 | 홈 '시작 가이드' 4단계, 주간보고에 '이번 주 내 메모' → 팀원 없이도 초안 생성 |
| 시간이 진짜 줄었나? | 체감만 | 홈 '이번 주 아낀 시간'(기능별 표준시간 × 사용 횟수, Σ 추정 표시) |
| AI가 내 기준을 아나? | 일반론 | 내 노하우 → 모든 AI 기능 반영, 리뷰에 '팀장님 기준으로 본 결과'(✓/✗) |
| 놓치는 사람·약속은? | 케어 레이더 | 홈에서 바로 스크롤 이동 |
| 윗선 보고에 쓸 숫자? | 화면 안에만 | 팀 성과 '보고용 문장 복사' |
| 팀원에게도 좋은가? | 제출 창구 | 팀장 가이드 + 최근 받은 피드백 → 다시 묻지 않아도 됨 |
| 로그인 첫 화면 메시지 | 기능 나열 | 팀장의 결과(시간·놓치지 않기·내 방식) 중심 문구 |
