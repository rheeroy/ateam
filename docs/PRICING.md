## 2. 설계 이유

**① 핵심 AI를 차감하지 않는다.** "한 번에 2크레딧" 같은 표시는 팀장이 아껴 쓰게 만들어 습관을 막는다. 매일 쓰는 기능은 구독에 넣고, 남용만 공정 사용 한도로 막는다. 사용자는 숫자를 신경 쓰지 않는다.

**② 기록 도구는 잠그지 않는다.** 체크인·공유·목표 관리는 팀원들이 매주 쓰는 도구다. 잠그면 팀의 습관이 깨지고 팀장이 떠난다. 기록은 계속 쌓이게 두고 해석만 막으면, 시간이 갈수록 "내 팀 데이터가 쌓여 있는데 못 본다"가 전환 동기가 된다.

**③ 체험은 30일.** AI가 패턴을 보려면 체크인이 4주는 쌓여야 한다(인사이트 레벨 L2 조건). 14일은 가치를 보기 전에 끝난다.

**④ 비싼 작업만 크레딧.** 평가 초안·계획서 전체 초안처럼 입력이 크고 드물게 쓰는 작업만 크레딧으로 둔다.

**⑤ 결재 문턱 아래.** 팀장 개인 경비로 처리할 수 있는 월 ₩2~3만 원대. 팀원 1인당 환산 ₩2,400(Pro 12명 기준)으로 기존 전사형 SaaS(1인당 ₩6,000~)보다 싸다.

### 원가 방어 장치 (코드에 반영)

1. 모델 분리 — 일간 인사이트는 Haiku, 나머지는 Sonnet (`AI_MODEL_FAST`, `AI_MODEL_SMART`)
2. 예약 인사이트는 **최근 14일 활동이 있고 AI가 켜진 팀만** 만든다 (`active_ai_teams`)
3. 홈의 신호는 규칙·모델 계산이라 AI를 부르지 않는다. AI는 하루 한 번 엮어서 해석만 한다
4. 공유(승인 불필요)·숫자 업데이트·글은 1차 검토를 돌리지 않는다
5. 판단 보류는 무료 — 근거가 기준 미만이면 AI를 부르지 않는다
6. 프롬프트 캐시, 크기 상한(파일 20MB, 본문 6만 자), 기능별 출력 토큰 상한

## 4. 운영 규칙

| 환불 | 결제 후 7일 이내·프리미엄 크레딧 10% 미만 사용 시 전액 환불 (법무 검토 후 확정) |
